# Shared Memory Game

2024년 게임서버프로그래밍입문 수업 프로젝트  
세 개의 독립적인 프로세스가(서버1, 클라이언트2) 공유 메모리를 통해 정보를 주고받으며 상호작용하는 게임 서버 프로그래밍 실습 프로젝트입니다.

---

## 프로젝트 개요

- 3개의 독립 프로세스 간 공유 메모리를 사용해 데이터 공유  
- Signal을 통해 프로세스 간 통신 및 이벤트 전달  
- 기본적인 IPC (Inter-Process Communication) 구현 및 동기화 학습 목적  
- C 언어 기반 구현

---

## 주요 기능

- 프로세스 간 공유 메모리 생성 및 접근  
- Signal 기반 이벤트 전달 및 처리  
- 동기화 이슈 해결을 위한 시그널 및 공유 메모리 전략 적용  

---

## 사용 기술

- C 언어  
- POSIX 공유 메모리 및 Signal 처리  
- CMake 빌드 시스템

---

## 빌드 및 실행 방법

1. CMake 빌드 디렉토리 생성 및 이동  
2. 빌드 실행
